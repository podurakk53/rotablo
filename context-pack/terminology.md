# Rotablo Terminology Quick Context

Use `../docs/Rotablo_Terminology_Standard_v1.md` as the canonical source.

## Terms That Must Stay Stable

- `route`: published editorial backbone
- `stage`: ordered primary driving unit inside a route
- `sideQuest`: optional detour attached to a stage, not a route family member
- `routeSession`: canonical runtime object for active/incomplete/completed route use
- `route warning`: static advisory card derived from road character, condition sensitivity, and vehicle compatibility
- `advisory warning`: risk information, not go/no-go decision
